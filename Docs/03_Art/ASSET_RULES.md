# IslandLife Asset Rules

Version: T0.1
Owner: PM

## 1. Asset Source Rules

Reusable resources may be used when:

- License allows project use.
- Style matches IslandLife direction.
- Modification rights are clear.

## 2. Asset Categories

Assets are managed by category:

- Characters
- Animals
- Environment
- Buildings
- UI
- Effects
- Items

## 3. Consistency Rules

All assets must match the frozen visual direction.

Do not introduce assets that create visual style conflicts.

## 4. Reuse Principle

Prefer suitable existing resources over rebuilding common assets from zero.

Custom development should focus on unique IslandLife gameplay elements.
