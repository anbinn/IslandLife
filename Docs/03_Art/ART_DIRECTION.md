# IslandLife Art Direction

Version: T0.1
Owner: PM

## Visual Goal

IslandLife should create a warm, relaxing island exploration and management experience.

The visual direction combines:
- Cozy management game atmosphere.
- Exploration adventure feeling.
- Clear and readable mobile presentation.

## Reference Direction

Reference qualities:
- Stardew Valley: cozy management atmosphere.
- Dave the Diver: approachable game presentation and charm.
- Survival games: exploration and resource discovery.

The project should not copy any specific game. It should establish its own unified style.

## Style Principles

- Consistent visual language is more important than individual asset quality.
- New assets must match existing proportions, colors, and rendering style.
- Avoid mixing unrelated art styles.
- Prioritize readability on mobile screens.

## Long-term Rule

The visual foundation should remain stable during future content expansion.
New animals, plants, buildings, items, and UI elements should extend the same style rather than redesign it.
