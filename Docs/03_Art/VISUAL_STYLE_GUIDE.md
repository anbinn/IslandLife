# IslandLife Visual Style Guide

Version: T0.1
Owner: PM

## Overall Style

Target:
- Cozy.
- Bright.
- Friendly.
- Easy to understand on mobile.

## Environment

Island environments should provide:
- Exploration space.
- Natural variation.
- Clear resource locations.
- Room for future expansion.

The first island should feel complete, not like a small test room.

## Character and Object Style

Requirements:
- Simple readable silhouettes.
- Consistent scale relationships.
- Clear interaction feedback.

## UI Style

UI should follow:
- Simple operation.
- Clear hierarchy.
- Friendly game feeling.
- Consistent icon language.

## Animation Style

Prioritize:
- Smooth interaction feedback.
- Clear gathering actions.
- Clear state changes.

Avoid unnecessary complex animation that affects performance.
