# IslandLife Development Workflow

## Source of Truth

GitHub Repository is the single source of truth for project changes.

All meaningful changes must exist as GitHub commits before they are considered part of the project history.

## Development Flow

PM
↓
Dispatch Task
↓
Kiro Worker Execution
↓
GitHub Commit
↓
PM Review Diff
↓
Acceptance
↓
Local Sync Verification

## Rules

- No untracked feature development outside the repository workflow.
- No large undocumented changes.
- Every task must have a clear objective and acceptance criteria.
- Commit history must explain what changed.
