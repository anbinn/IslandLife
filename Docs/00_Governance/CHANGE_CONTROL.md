# Change Control Rules

## Principle

IslandLife prioritizes controlled iteration over uncontrolled expansion.

## Change Categories

### Governance Change

Managed by PM only.

### Product Decision

Requires product direction confirmation.

### Development Change

Executed through Dispatch and reviewed through GitHub Diff.

## Review Requirements

Before acceptance:

- Confirm intended files changed.
- Confirm no unrelated modifications.
- Confirm tests or verification steps.

## Historical Record

GitHub commit history is the project audit trail.
