# Project Structure Rules

## Purpose
Define the repository structure and ownership boundaries for IslandLife.

## Rules
- GitHub repository is the single source of truth.
- Every meaningful change must be traceable through commits.
- PM owns governance documents and workflow definitions.
- Worker owns execution tasks only.
- Product decisions require PM approval before implementation.

## Directory Ownership
- Docs/: project documentation and specifications.
- Assets/: managed game assets and licenses.
- Project/: game source code.
- Tests/: verification and validation materials.

## Change Principle
Prefer small, reviewable changes over large uncontrolled modifications.
