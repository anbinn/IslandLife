# IslandLife Asset Tracking

Version: T0.1
Owner: PM

## Asset Record Requirements

Each external or reusable asset should record:

- Name
- Source
- License
- Modification permission
- Usage location
- Style compatibility review

## Rule

Unrecorded assets cannot enter the production build.
