# IslandLife Asset Library Management

Version: T0.1
Owner: PM

## 1. Purpose

Define how game assets are collected, reviewed, stored, and reused.

## 2. Asset Workflow

Source discovery → License check → Style review → Integration → Record update

## 3. Asset Categories

- Characters
- Animals
- Environment
- Buildings
- UI
- Effects
- Items
- Animation

## 4. Reuse Principle

Prefer existing suitable assets before creating new assets.

Unique gameplay elements may use custom assets.

## 5. Quality Requirements

Every asset must pass:

- Visual consistency check.
- Performance impact check.
- License verification.
- Naming convention check.
