# IslandLife Product Overview

Version: T0.1
Owner: PM

## 1. Product Vision

IslandLife is a lightweight island survival and management game focused on exploration, resource collection, crafting, construction, and gradual island development.

The product goal is to provide a relaxing but meaningful progression loop with strong player ownership of their island.

## 2. Platform Strategy

Initial target:
- Douyin Mini Game platform.

Future consideration:
- Android standalone version.
- iOS standalone version.

The first version prioritizes fast validation, stable performance, and user feedback.

## 3. Core Experience

The player should experience:

Explore → Collect → Craft → Build → Expand → Discover

The island is the player's long-term development space.

## 4. Product Principles

- Build a complete small experience before expanding scope.
- Keep visual style and technical foundation stable.
- Prefer iteration of content over repeated redesign of core systems.
- Prioritize smooth performance and accessibility on mobile devices.
- Reuse suitable licensed resources when possible.

## 5. Initial Scope Control

The first playable version should focus on a small but complete loop.

Expected first version elements:
- Basic player movement.
- Island environment.
- Resource gathering.
- Basic crafting.
- Basic construction.
- Simple survival values.

Large systems are reserved for later iterations.

## 6. Non-Goals

The initial project will not attempt to become:
- A full Minecraft-style sandbox.
- A large open world.
- A complex multiplayer game.
- A complete simulation ecosystem.

## 7. Expansion Direction

Future updates may expand through:
- New animals.
- New resources.
- New island areas.
- Farming systems.
- Exploration events.
- Boss encounters.

Expansion should preserve the original visual style and gameplay foundation.
