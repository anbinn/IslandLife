# Local Development Environment

## Purpose
Define the local environment required for PM acceptance, testing, and development verification.

## Principles
- PM local environment must be able to reproduce Worker results.
- GitHub is the source of truth.
- Local builds are for verification, not the primary development source.

## Required Setup
- Git client
- GitHub access
- Game engine environment
- Required SDK/toolchain
- Build and debug tools

## Verification Flow
GitHub Commit → Local Sync → Build → Test → PM Acceptance
