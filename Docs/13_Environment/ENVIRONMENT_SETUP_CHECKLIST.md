# Environment Setup Checklist

## Purpose
统一开发、审核、测试环境准备标准。

## Required Setup

- GitHub access
- Git client
- Kiro development environment
- Game engine environment
- Build tools
- Test device environment

## Verification

Before development starts:

1. Clone repository successfully
2. Pull latest main branch
3. Run project locally
4. Confirm build pipeline
5. Confirm PM can reproduce the same result
