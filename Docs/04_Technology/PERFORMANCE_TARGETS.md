# IslandLife Performance Targets

Version: T0.1
Owner: PM

## 1. Performance Objective

The first version must prioritize smooth gameplay experience on common mobile devices.

## 2. Requirements

- Avoid noticeable frame drops during normal gameplay.
- Control memory usage.
- Optimize loading times.
- Keep asset sizes manageable.

## 3. Optimization Direction

Optimization should focus on:

- Asset management.
- Scene loading.
- Object count control.
- Efficient game logic.

## 4. Principle

Gameplay scope may be reduced, but basic smoothness cannot be sacrificed.
