# IslandLife Technology Architecture

Version: T0.1
Owner: PM

## 1. Technology Goals

The technology foundation must support:

- Fast iteration.
- Stable mobile performance.
- Future expansion to Android and iOS.
- Maintainable AI-assisted development.

## 2. Platform Strategy

Initial target:
- Douyin Mini Game platform.

Future consideration:
- Android standalone.
- iOS standalone.

## 3. Performance Principles

Performance is a core requirement.

Priorities:

- Stable frame rate.
- Low memory usage.
- Efficient asset loading.
- Mobile device compatibility.

## 4. Architecture Principles

- Keep systems modular.
- Avoid unnecessary complexity in the first version.
- Build expansion points for future content.
- Prefer proven solutions over custom systems.

## 5. Development Rules

Technical decisions must be documented before major implementation.

Large architectural changes require PM review.
