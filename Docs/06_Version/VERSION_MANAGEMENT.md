# IslandLife Version Management

Version: T0.1
Owner: PM

## 1. Purpose

Define version planning, iteration tracking, and release management rules.

## 2. Version Principles

- Every version has a clear objective.
- Each iteration must have documented scope.
- Avoid uncontrolled feature expansion.
- Maintain playable quality at every milestone.

## 3. Version Flow

Planning → Dispatch → Development → GitHub Review → Testing → Release

## 4. Milestone Rules

Major milestones require PM review before moving forward.

## 5. MVP Priority

The first playable version focuses on validating the core gameplay loop, performance, and player feedback.
