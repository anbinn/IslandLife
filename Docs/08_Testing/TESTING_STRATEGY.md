# IslandLife Testing Strategy

Version: T0.1
Owner: PM

## Purpose
Define testing requirements before development begins.

## Testing Principles

- Every major feature requires verification.
- Performance testing is required for mobile targets.
- Bugs must be reproduced before fixing.
- Changes must be traceable through Git history.

## Test Categories

- Functional testing
- Performance testing
- Device compatibility testing
- Asset loading testing
- Regression testing

## Acceptance Rule
A feature is complete only after implementation, verification, and PM review.
