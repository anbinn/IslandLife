# IslandLife Development Readiness Checklist

Version: T0.1
Owner: PM

## Purpose

Verify that the project foundation is ready before Worker begins implementation.

## Checklist

- Governance documents completed.
- Product direction documented.
- Core gameplay documented.
- Art direction documented.
- Technology direction documented.
- Asset management rules documented.
- Version management rules documented.

## Before First Development Dispatch

PM must confirm:

- Engine and project structure are frozen.
- Initial milestone scope is clear.
- Acceptance criteria are defined.
- Performance requirements are included.
- Worker task boundaries are explicit.

## Rule

No feature implementation starts before required design documents are reviewed.
