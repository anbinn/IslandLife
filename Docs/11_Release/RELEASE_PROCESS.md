# IslandLife Release Process

Version: T0.1
Owner: PM

## Purpose

Define the release process from development completion to user testing.

## Release Flow

Development → Internal Test → PM Review → Build Verification → Release Candidate → Release

## Requirements

- All changes must have Git history.
- All release builds require PM approval.
- Known critical issues must be resolved before release.

## Release Records

Each release must record:

- Version number
- Changes
- Known issues
- Test results
