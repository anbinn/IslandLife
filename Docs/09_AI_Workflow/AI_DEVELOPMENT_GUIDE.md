# IslandLife AI Development Guide

Version: T0.1
Owner: PM

## Purpose

Define how AI agents participate in IslandLife development.

## Roles

PM:
- Define requirements.
- Review changes.
- Control architecture and standards.

Worker:
- Execute assigned tasks.
- Modify only approved scope.
- Commit and push changes.

## Development Rules

- GitHub is the source of truth.
- Every change requires traceable commits.
- Large uncontrolled changes are prohibited.
- Existing systems must be reviewed before modification.

## Review Flow

Dispatch → Implementation → Commit → PM Review → Acceptance
