# IslandLife Core Gameplay Loop

Version: T0.1
Owner: PM

## Core Loop

Explore → Collect → Craft → Build → Expand → Discover

## Player Experience Goal

The player should feel that the island gradually becomes their own home through continuous exploration and development.

## First Version Loop

1. Explore the initial island area.
2. Gather basic resources.
3. Craft simple tools.
4. Build basic structures.
5. Improve survival conditions.
6. Unlock more exploration opportunities.

## Island Scale Principle

The first island should not be a tiny tutorial area and should not become an uncontrollable large open world.

Requirements:
- Provide enough exploration space to create discovery and ownership feelings.
- Leave expansion space for future regions or additional islands.
- Maintain mobile performance targets.
- Avoid excessive map complexity in the first version.

The first island is a complete playable space, not only a test area.
