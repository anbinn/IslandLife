# IslandLife MVP Scope

Version: T0.1
Owner: PM

## Goal

Create a small but complete playable island survival experience for early validation.

## Included

- One player character.
- One main island.
- Basic movement.
- Resource gathering.
- Basic crafting.
- Basic building placement.
- Basic survival values.
- Limited wildlife interaction.

## Island Design Requirement

The initial island must provide meaningful exploration.

It should:
- Have multiple areas to discover.
- Allow future expansion.
- Avoid feeling like a small demonstration scene.
- Remain optimized for mobile platforms.

## Excluded For MVP

- Massive open world.
- Multiplayer.
- Complex ecosystem simulation.
- Large combat systems.
- Full automation systems.

Future content expands on the same foundation.
